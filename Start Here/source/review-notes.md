# Start Here 中文稿：人的意见（2026-11-11，先记，最后统一改）

## 1. 第 2 页开头的场景不够生动
- 原句：“花半个小时贴代码、讲架构，再写一长串 DO 和 DO NOT”
- 人给的方向：“花半个小时去找有关的代码，粘贴给 Copilot，加一堆代码功能的介绍、需求的背景，写很多要做的事（to do list）和 Don’t，然后祈求它能 100% 完成这个任务。”
- 背后的思想（要进长期记忆和 skill）：写文章要动脑，不是按规则套模板。假设我就是作者本人，面对没耐心、质疑 AI 的老板和同事，要把 harness 卖给他们，我会怎么写。场景要写出读者亲手做过的具体动作和当时的心情。

## 2. 纵向和横向的举例不准
- 等人审批不是纵向，是让人用得放心，属于横向。
- 纵向：agent 能干多少活、懂多少。懂我们的 domain 知识，能读懂需求；能更新工单、查 pipeline 报错；能去 DEV、IST 跑测试、查数据；能做 RCA。
- 横向：让人用起来安心和舒服：审批、独立检查、围栏、可观测性和可审计，以及不用写长 prompt。
