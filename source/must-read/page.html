2 Ask the Harness Guide/

An agent that helps you understand the harness and learn AI harness engineering. It is not a tutorial.

For anyone who wants to go deeper: leads, architects, curious colleagues. How Open Microsoft 365 Copilot, pick the Harness Guide agent, and ask. It answers four kinds of question, from shallow to deep:

  1. The harness itself. What is this harness, and what problem does it solve?
  2. Its common features. What does the board show, and what does ‘waiting for you’ mean?
  3. How it is designed and built, with the places in the code. How does the gate block dangerous commands, and where are its rules?
  4. The AI harness engineering ideas behind it, with links to smarshu.com. Why isn't a rule in the prompt enough to keep the agent safe?

Do not ask it for step-by-step how-to (How do I start a task?): it gives a short answer and sends you to the harness tutorials in 3 Courses/, which show each step on screen.

4 Install the harness/

Install the harness on your computer, step by step, up to your first task.

For the team. How Follow Install the harness.pdf page by page.

After installing: two courses run inside the harness. In VS Code, open Copilot chat and type:

  • /harness-rookie-quick-start takes a newcomer through a first task.
  • /harness-rookie-wondering teaches all of harness engineering and how this harness does it. The agent reads the harness code, so it is the most direct way to learn, but it spends GitHub Copilot credits.
