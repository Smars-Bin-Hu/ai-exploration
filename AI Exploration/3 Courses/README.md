# Courses

Videos with animation, no long text. One or two new ones a week. Watch once and you have it.

| Folder | What it is |
|---|---|
| `Harness tutorials/` | How to use the harness, day to day |
| `Basic/` | AI harness engineering from the start |
| `Advanced/` | The same, in depth |
| `Lessons/` | Wrong turns taken while building the harness |

Each folder holds its videos in order. `Course list.pdf` shows what is out and what is planned.
